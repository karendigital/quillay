# El Quillay de Pirque — sitio web

Landing de arriendo de piscina y terraza en Pirque (hasta 20 personas).

## Estructura
- `index.html` — la página completa (estilos y código incluidos)
- `assets/img/` — fotos del espacio
- `.nojekyll` — le indica a GitHub Pages que publique los archivos tal cual

## Cambiar una foto
Reemplaza el archivo en `assets/img/` manteniendo el mismo nombre
(por ejemplo `portada.jpg`). Usa nombres sin espacios ni tildes.
